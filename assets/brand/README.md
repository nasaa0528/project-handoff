# Brand assets

Not demo artifacts. Nothing in this folder is fabricated evidence and nothing in it
carries a FAKE label — the rule in the parent folder applies to the demo artifacts
beside it, not to the logo.

| File | What it is |
|---|---|
| `logo-mark.svg` | The mark, vector source. 500x500 viewBox, azure `#0497FE` on the pale ring |
| `logo-mark.png` | The same mark rasterised, 500x500 RGBA. Use it for the favicon |
| `logo-lockup.jpg` | Horizontal lockup, mark plus the HANDOFF wordmark, 804x250 on white |

The wordmark paths in `logo-mark.svg` carry no fill, so they render black. A light
version for dark backgrounds does not exist yet.

**Palette conflict, unresolved on purpose.** The logo's azure `#0497FE` is not the
design system's proof navy `#1D4E89`. Which one moves gets decided after the Sep 11
freeze, not before it.
