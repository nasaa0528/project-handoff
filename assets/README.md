# Assets

Two unrelated things live here. `brand/` and `cover.png` are real project
material. Everything else is a demo artifact and the rule below governs it.

## Cover

`cover.png`, 1920x1080. The hashgraph converges into a signature and the seal.

The upper left is empty on purpose. The wordmark and the used-tech logos go there
as a later layer, once a light wordmark exists. Until then the cover is usable as is.

No node labels and no rosette: a judge lane would imply Tier 3, and a rosette would
imply scarcity behind a credential that is an allowlist this week.

## Demo artifacts

**Every one of them is fabricated.** Hard rule 7: never a real contract, filing, PII,
or anything that could read as a genuine professional opinion.

Every artifact that appears on camera carries a visible **FAKE** label in the artifact
itself, not just in the filename. A judge watching the recording has to be able to see
it without pausing.

Large files and recordings go to shared Drive instead. This folder stays small.
