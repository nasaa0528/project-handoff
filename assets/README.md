# Demo assets

**Everything in here is fabricated.** Hard rule 7: never a real contract, filing, PII,
or anything that could read as a genuine professional opinion.

Every artifact that appears on camera carries a visible **FAKE** label in the artifact
itself, not just in the filename. A judge watching the recording has to be able to see
it without pausing.

Large files and recordings go to shared Drive instead. This folder stays small.

`demo/` holds the fabricated order the apps import at build time: the task spec and
the artifact under review. Both say FAKE in their first word.
